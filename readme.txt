                                          Игра «Запомни» 

Описание
Десктопное приложение  игра на запоминание пар карточек.


Управление
- Выберите уровень сложности кнопками «Легко», «Средне», «Сложно».
- Кликайте по карточкам, чтобы открыть их.
- Найдите все пары за минимальное время и с минимумом ошибок.
Структура проекта
- `oop.py` — весь код приложения.
- `report.txt` — отчёт о работе приложения (создаётся автоматически при выходе).
- `memory_scores.json` — сохранённые рекорды (создаётся автоматически).

## Реализованные требования
- Все сущности описаны через классы: `GameEntity`, `Card`, `Deck`,
  `GameRecord`, `ScoreCollection`, `Player`, `MemoryGame`.
- Абстрактный класс `GameEntity` с методом `describe()`.
- Переопределены специальные методы: `__eq__`, `__lt__`, `__hash__`,
  `__str__`, `__repr__`, `__len__`, `__iter__`, `__getitem__`, `__contains__`.
- Геттеры и сеттеры через `@property`.
- Вместо `dict` используется собственный класс `ScoreCollection`.
- 12+ кастомных UI-компонентов (наследники `ft.*`).
- Все компоненты выровнены.
- При закрытии приложения создаётся отчёт `report.txt`.
